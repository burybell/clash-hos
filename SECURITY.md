# Security Policy

## Supported versions

Clash HOS is pre-release software. Security fixes are applied to the latest default branch; older snapshots are not maintained as supported releases.

## Reporting a vulnerability

Do not open a public issue for credential exposure, VPN route bypass, unsafe native memory access, arbitrary code execution, signing problems, or controller exposure.

Use GitHub private vulnerability reporting for this repository. If unavailable, contact the repository owner privately through their GitHub profile and request a secure reporting channel. Do not include live credentials in the initial message.

Include the affected commit, HarmonyOS/device information, sanitized reproduction steps, expected impact, and whether the issue is already public. No fixed response-time SLA is currently offered.

## Sensitive data

Subscription URLs, tokens, node credentials, certificates, signing files, device identifiers, and full runtime logs are sensitive. Replace them with synthetic values before sharing any artifact.
